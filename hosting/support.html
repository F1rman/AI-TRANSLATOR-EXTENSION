A little help.

Getting started

Pin AI Translator in Chrome, open it, and sign in with Google. Choose your target language; Ukrainian is selected initially. Enter text or select a phrase on a webpage and click the small translation icon.

Translate a page

Use Translate page in the extension popup. A small panel shows progress and lets you stop translation or restore the original. New page content is translated while this mode is active. A page may contain more text than your remaining daily allowance; already translated sections stay readable when the allowance runs out.

Daily allowance

Free access includes 20,000 source characters per account each day, resetting at midnight UTC. Spaces and punctuation count. Successful translated jobs consume the allowance; unsuccessful jobs release their reservation.

Where it works

AI Translator works on ordinary HTTP and HTTPS pages where you have allowed site access. Chrome internal pages, Chrome Web Store pages, the browser's PDF viewer, text inside images, canvas content, and closed Shadow DOM are not supported. Translation can change line wrapping because languages have different text lengths.

Something went wrong

For a connection error, check your network and retry. If sign-in expires, open the extension and sign in again. If a website continually replaces its content, stop and restart page translation. For further help or a privacy request, use the developer contact on the Chrome Web Store listing. Include the error code and Chrome version, without passwords, API tokens, or private page text.

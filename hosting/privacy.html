PRIVACY POLICY · OCTOBER 24, 2026

What the extension sends

When you request a translation, AI Translator sends the text you enter or select, or eligible page text when you turn on page translation, to its translation server. The server forwards a translation prompt to the AI generation API at balubenko-ai.web.app, which uses OpenAI. While page translation is active, newly appearing page text is also translated. Selecting text alone does not send it when the default icon mode is used; the optional instant mode sends selected text automatically.

The extension does not send full page HTML, browsing history, cookies, passwords, or form field values. It skips editable controls, code blocks, hidden content, and its own interface. Visible page text can still include personal information; use page translation only where you want that text processed.

Pro image translation

When a Pro user chooses Translate image from a webpage image’s context menu, the extension downloads that selected static PNG, JPEG or WebP without website cookies and sends its bytes and chosen languages to the translation server. The server forwards it to our AI API on Cloud Run, which uses OpenAI vision to recognize and translate the text, then passes exact text replacements to OpenAI image editing to create a translated PNG. The website URL is not sent to the translation backend. The original image is not replaced on the website. A dedicated extension tab shows the original and result, and lets you cancel or download the PNG.

Image translation requires manually granted Pro access and allows five successful images per account per UTC day. Failed or cancelled jobs release their reservation. Images must be no larger than 10 MB and 20 megapixels. AI image editing may change small visual details or render some text incorrectly; inspect the result before using it.

Google account and daily allowance

Google sign-in is handled by Chrome Identity and Firebase Authentication. Basic account details (account identifier, name, email, and profile image when provided) support authentication and the account display. The server stores daily character and image counters, active-job information, and a server-managed Pro entitlement tied to your account identifier. Both Free and Pro include 20,000 source text characters per UTC day. Pro is currently granted manually; the extension has no payment or subscription checkout. Authentication tokens remain in the extension's trusted context and are not shared with webpages.

Storage and retention

Language and display preferences are stored locally in Chrome. Originals needed to restore a translated page remain in that page's memory and are discarded when the page closes. The extension has no translation-history feature. For an image request, session storage temporarily retains the selected image URL, languages, request key and job ID. Requests expire after 24 hours; expired session records are removed during the next image action, on sign-out or when the browser session ends. It does not store image bytes in Chrome storage. The result tab holds image previews in memory.

Server-side jobs temporarily store source text and translation results in Firestore. Job records are marked for automatic expiration after 24 hours; actual removal follows Firestore TTL processing and may occur later. Daily usage counters contain counts, not page text or page URLs. Operational logs are designed to exclude translation text and credentials. Firebase Authentication retains account records to support future sign-in.

Original images and translated PNGs are kept in a private Cloud Storage bucket. Only the job owner can access them through authenticated server routes. Job access expires after 24 hours; background lifecycle deletion may occur later. Failed and cancelled jobs trigger immediate deletion attempts, with lifecycle cleanup as a fallback. The image bucket has soft delete and versioning disabled. Pro grants remain until an administrator revokes them.

AI processing

Text generation requests use OpenAI’s store: false option. Image translation uses OpenAI’s image edits API. This is not a guarantee of zero retention by the provider. Provider processing and retention are governed by OpenAI's policy; Google/Firebase processing is described in Google's privacy policy.

Your controls

You can stop page translation, restore original text, disable selection translation, sign out, or uninstall the extension. Uninstalling removes local extension storage; server-side job expiration is independent. For account or privacy requests, use the developer contact shown on the extension's Chrome Web Store listing.

Use of data

Data is used to provide translation, authenticate access, enforce usage limits, and operate the service. AI Translator does not use page text or images for advertising or sell them. Operational timing logs contain stage names, counts and durations, without translation text, image contents or authentication tokens. Changes to this policy will be published on this page.

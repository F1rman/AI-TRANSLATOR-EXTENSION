# AI Translator для Chrome

Manifest V3 розширення для перекладу введеного й виділеного тексту та, з Pro, вебсторінок. Google-вхід, локальна історія, світла/темна тема. Поточна версія — **1.3.1**.

## Тарифи

| | Free | Pro |
| --- | --- | --- |
| Ціна | Безкоштовно | US$4.99/місяць або US$39.99/рік |
| Місячна квота | 100 000 символів | 2 000 000 символів |
| Один переклад | До 4 000 символів | До 50 000 символів |
| Переклад сторінок, тон, контекст | Ні | Так |
| Видима локальна історія | Останні 20 записів | До 1 000 записів |

Рахуються Unicode-символи вихідного тексту, включно з пробілами. Free оновлюється першого числа о 00:00 UTC. Pro оновлюється щомісяця від початкової дати підписки, також за річної оплати; залишок не переноситься. При скасуванні поновлення доступ діє до кінця оплаченого періоду.

Контекст Pro — до 2 000 символів видимого навколишнього тексту, лише за ввімкненого перемикача. Поля вводу, паролі, прихований текст і HTML не збираються як контекст. Історія зберігається в IndexedDB окремо за акаунтом і середовищем, без хмарної синхронізації: до 1 000 записів або 25 MiB; її можна вимкнути або очистити. Пониження тарифу саме по собі записи не видаляє.

## Встановлення

1. Зібрати live або test пакет командами нижче.
2. Відкрити `chrome://extensions`, увімкнути режим розробника й завантажити `extension/dist` або `extension/dist-test` через Load unpacked.
3. Закріпити іконку, оновити вже відкриті сторінки та увійти через Google.

Попап завжди має **420px** ширини — постійна вимога в [extension/AGENTS.md](extension/AGENTS.md). Натискання «Сторінка» або «Перекласти сторінку» у Free відкриває купівлю Pro. У Pro переклад продовжується після закриття попапу; сторінкові кнопки зупиняють переклад або відновлюють оригінал.

На першому встановленні відкривається локальна welcome-сторінка; оновлення її повторно не відкриває. Після п’яти унікальних успішних завдань у спокійному стані попапу може з’явитися запит чесного відгуку. Перше закриття відкладає його на 14 днів; друге закриття або перехід до оцінки вимикає назавжди. Текст перекладів у лічильнику не зберігається.

Підтримуються HTTP(S)-сторінки, доступні фрейми та відкриті Shadow DOM. Поля, редаговані області, прихований текст і код пропускаються. Внутрішні сторінки Chrome, Web Store, canvas і закриті Shadow DOM не підтримуються.

## Розробка й пакування

```sh
npm ci
npm --prefix extension ci
npm --prefix extension run typecheck
npm run test:extension
npm run build
npm run package
npm run build:test
npm run package:test
npm run qa:browser
```

Готові пакети: `artifacts/ai-translator-1.3.1.zip` і `artifacts/ai-translator-1.3.1-test.zip`. Маркетингові файли `meta/` до ZIP не входять. Обидві збірки зберігають Store ID **aieamemimbcbbnmakifejomadhegogge** та OAuth, тому одночасно встановлюється одна з них. Test додає до локалізованої назви `(Test)` і використовує окремі API/білінг.

Публічні Firebase/OAuth налаштування — `extension/.env.production`, приклад — `extension/.env.example`. `API_ACCESS_TOKEN` і приватні ключі не належать до налаштувань розширення. Джерела live/test origin — `extension/billing-targets.json`.

Браузерні тести перевіряють зібраний попап Chrome, DOM-переклад, welcome та локалізацію з контрольованими даними. Вони не підтверджують справжній Google-вхід або якість live AI.

## Локалізація й Store-матеріали

[meta/index.html](meta/index.html) — локальний дашборд десяти завдань; [meta/REPORT.md](meta/REPORT.md) — статуси й обмеження. Підготовлено 55 описів/каталогів і по п’ять локалізованих скриншотів для кожної локалі. Локалізовано маркетингові підписи навколо справжнього англомовного UI; головний інтерфейс перекладача залишається англійською/українською. Welcome використовує `chrome.i18n`; метадані й рядки onboarding/review включені в `_locales`.

Щоб застосувати оновлені каталоги з `meta/locales` до вихідних ресурсів, запусти `node scripts/promote-listing-locales.mjs`, потім обидві збірки. Скрипт перевіряє ключі, довжину назви/опису та екранує літеральні долари цін для Chrome i18n.

Незалежна редакторська перевірка носіями мов і публікація в Chrome Web Store залишаються окремими діями власника. Чекбокси дашборду відображають його підтвердження; готовність локальних результатів показана окремо.

## Backend

Стан середовищ — `deployment.json` і `deployment.test.json`. API `/v2` повертає квоту символів і можливості тарифу. Резерв створюється транзакційно до AI-завдання, успіх списує його один раз, помилка/скасування звільняє. Пріоритетні Pro й звичайні Free завдання використовують окремі Cloud Tasks черги. Ключі AI залишаються на сервері.

Налаштування сервера — [backend/README.md](backend/README.md), ліміти — [backend/app/limits.json](backend/app/limits.json), оплата — [docs/BILLING.md](docs/BILLING.md). Ручні Pro-grants керуються `scripts/set_pro_access.py` і перевіряються за Firebase UID. Збірка розширення не розгортає backend і не публікує Store-пакет.

```sh
backend/.venv/bin/python -m pytest backend/tests -q
python3.12 scripts/deploy_backend.py --environment live
python3.12 scripts/deploy_hosting.py
```

type ReviewState = {

  state: 'counting' | 'later' | 'done';
  dismissals: number;
  laterUntil?: number;

const REVIEW_KEY = 'marketingReviewV1';
let reviewTransaction: Promise<unknown> = Promise.resolve();
function updateReview<T>(fn: (value: ReviewState) => T | Promise<T>): Promise<T> {
  const next = reviewTransaction.then(async () => {
    const saved = (await chrome.storage.local.get(REVIEW_KEY))[REVIEW_KEY] as ReviewState | undefined;
    const state = saved ?? { successes: 0, completedJobIds: [], state: 'counting', dismissals: 0 };
    const result = await fn(state);
    await chrome.storage.local.set({ [REVIEW_KEY]: state });
    return result;
  });
  reviewTransaction = next.catch(() => undefined);
  return next;
}
async function recordTranslationSuccess(job: Job): Promise<void> {
  if (job.status !== 'completed' || !job.translations?.length ||
      job.translations.some((part) => typeof part.text !== 'string' || !part.text.trim())) return;
  await updateReview((review) => {
    if (review.state === 'done' || review.successes >= 5 || review.completedJobIds.includes(job.id)) return;
    review.completedJobIds.push(job.id); // At most five IDs are retained; never store translation text.
    review.successes++;
  });
}
async function dismissReview(): Promise<void> {
  await updateReview((review) => {
    review.dismissals++;
    if (review.dismissals >= 2) review.state = 'done';
    else { review.state = 'later'; review.laterUntil = Date.now() + 14 * 24 * 60 * 60 * 1000; }
  });
}
async function rateReview(): Promise<void> {
  await chrome.tabs.create({
    url: `https://chromewebstore.google.com/detail/${chrome.runtime.id}/reviews`,
  });
  await updateReview((review) => { review.state = 'done'; });
}

    AI Translator – Text & Webpage Translator

    Description · 3065
    AI Translator helps you translate text while reading and working in your browser. Paste text into the popup, translate a selection on a webpage, or use the Pro webpage translator to read an eligible page in your chosen language.

TEXT TRANSLATION
• Translate typed or pasted text in the popup.
• Select text on a webpage and use the translation icon or context menu.
• Detect the source language automatically or choose it yourself.
• Copy the result and find completed translations in local history.

FREE
Free includes 100,000 source characters per calendar month and up to 4,000 characters per translation. Spaces count toward the limit. Your allowance resets on the first day of each month at 00:00 UTC; unused characters do not roll over.

Free uses neutral tone and shows the latest 20 history entries. Google sign-in is required to translate and track your account allowance.

PRO
Pro costs US$4.99 per month or US$39.99 per year and includes:
• 2,000,000 source characters per monthly subscription window, with up to 50,000 per translation. Annual billing still provides a separate monthly allowance.
• Page translation on eligible websites, including newly appearing text during an active session. Pause translation or restore the original text when needed.
• Neutral, formal, friendly and technical translation tones.
• Optional context from up to 2,000 visible surrounding characters on the current page. You control whether this is used.
• Access to up to 1,000 local history entries and a priority processing queue. Processing times can vary.

Your Pro allowance renews monthly from the subscription start date, including on the annual plan. Renewals do not carry unused characters forward. Manage or cancel renewal through your account; cancelling renewal keeps access until the end of the paid period.

HOW TO START
1. Pin AI Translator to the toolbar and open the popup.
2. Sign in with Google and choose your languages.
3. Paste or select text and translate. For webpage translation, choose Pro and then start translation on an eligible page.

PRIVACY AND LOCAL HISTORY
Requested source text is sent to the translation backend for AI processing. When instant-selection mode is enabled, selected text is sent automatically. An active Pro page session also sends eligible new page text as it appears. Optional Pro context excludes input fields, passwords and hidden text; it does not send page HTML as context.

History is stored in the extension on this device, separated by account and environment, without cloud synchronization. Recording can be disabled; entries can be deleted individually or cleared. Storage retains at most 1,000 entries or 25 MiB, removing the oldest when needed. Free shows the latest 20; downgrading alone does not delete older entries.

The interface is available in English and Ukrainian. Chrome internal pages and the Chrome Web Store cannot be translated.

    Translate Selected Text

    Description · 2191
    This extension allows you to translate the text selection using Google Translate whenever you want.

When the extension is installed select some text from a website, right click and select to which language you want to translate the selected text.

** FAQ: **
Q: Why choose this extension and not another one?
A: I designed this extension so that it didn't prompt the user for permissions. This way the final user knows that the extension doesn't have the permission to access the content of web pages and monitor the user activity on the Internet (other extensions of this type prompt for this permission). This extension has access only to the content of the selected text when the user clicks the extension context menu and it is used to create a Google Translate app with the text autocompleted.

You can configure from the options page which languages you want to show in the context menu.

    Category

    Productivity → Tools

    Single purpose

    Translate typed or selected text and, with Pro, eligible webpage text into a chosen language. Related controls provide language detection, optional visible page context, translation tones, local translation history, and restoring original webpage text.

    activeTab

    The popup reads selected text from the current tab’s accessible frames after the user opens the extension, using chrome.tabs.query and chrome.scripting.executeScript in extension/src/ui/main.tsx. This is a real current-tab user gesture flow. Because the package also declares persistent HTTP(S) host permissions for the selection icon, activeTab may be redundant on those sites; verify a narrower permission design separately before removal.

    contextMenus

    Adds Translate selection and Translate page commands using createMenus and chrome.contextMenus.onClicked in extension/src/background.ts. The selection command sends the chosen text to the content script; the page command starts the Pro workflow or opens the Pro purchase page for Free access. Browser context menu entries require this API permission.

    storage

    Uses chrome.storage.local for language, theme, interface, selection, tone and page-context preferences, and chrome.storage.session for account/environment-scoped popup drafts, pending requests, page sessions and job ownership. These extension-wide settings and recoverable service-worker state cannot use an individual website’s storage. Completed translation history separately uses local IndexedDB, partitioned by account and environment, without cloud sync. Evidence: extension/src/background.ts settings/saveSettings/withSession, extension/src/shared/drafts.ts, and extension/src/shared/history.ts.

    scripting

    Reads selected text from accessible frames when the user opens the popup, and injects packaged content.js if an existing user-selected page lacks the content script. Evidence: extension/src/ui/main.tsx popup selection capture and extension/src/background.ts startPage fallback. chrome.scripting is needed for those dynamic operations; no remote executable code is fetched.

    identity

    Uses chrome.identity.getAuthToken for Google sign-in and exchanges the credential for Firebase authentication. The verified account authorizes translation, tracks monthly character usage and connects subscription access. Sign-out clears cached tokens. Only openid, email and profile scopes are requested; Gmail, Drive, contacts and other account content are not requested. Evidence: extension/src/auth.ts login/logout/getIdToken and manifest.oauth2.scopes.

    webNavigation

    Enumerates documents and frames for user-started Pro page translation and handles their lifecycle. Navigation cancels jobs tied to old documents; eligible new frames join an active page session. History-state and fragment navigation end the old session. Evidence: extension/src/background.ts startPage/changePage getAllFrames and onCommitted/onDOMContentLoaded/onHistoryStateUpdated/onReferenceFragmentUpdated. activeTab does not provide these frame and navigation events. These events are used to manage active translation, not to compile browsing history.

    http://*/*

    Runs packaged content.js on ordinary HTTP webpages and accessible frames so the selected-text icon is ready on arbitrary sites. After user activation, Pro page translation reads eligible text, observes newly appearing text, replaces translations and restores originals. Optional context reads only eligible visible surrounding text. A fixed domain list would exclude arbitrary sites; activeTab alone would require manual activation before the current automatic selection-icon experience. Optional per-site permission would require a separate product-flow change. Evidence: manifest.content_scripts.matches/all_frames and extension/src/content/index.ts, dom.ts and context.ts.

    https://*/*

    Provides the same selection icon, requested text translation and user-started Pro page translation on ordinary HTTPS sites and accessible frames. It also allows HTTPS requests to translation and authentication services. Backend-only host access would not support translating arbitrary websites; activeTab alone would not supply the pre-existing selection icon before a toolbar/menu action. Evidence: manifest.host_permissions/content_scripts, extension/src/content/index.ts/dom.ts/context.ts, extension/src/background.ts api, and extension/src/auth.ts. Chrome internal pages and the Web Store remain restricted.

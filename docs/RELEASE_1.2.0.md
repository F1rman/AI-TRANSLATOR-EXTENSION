# AI Translator 1.2.0

Разові пакети перекладів підключені до робочого й тестового серверів. Покупка не надає Pro. Free залишається 10 000 слів і 5 зображень за календарний місяць UTC; ручний Pro — 200 000 слів і 150 зображень. Сервер витрачає місячну квоту першою, потім придбані пакети за порядком покупки. Придбані одиниці накопичуються без строку дії.

| Пакет | USD | Слова | Зображення |
|---|---:|---:|---:|
| Початковий | $4.99 | 50 000 | 2 |
| Для роботи | $9.99 | 150 000 | 5 |
| Максимальний | $19.99 | 400 000 | 12 |

Ціни задаються в центральному каталозі, у коді розширення вони не дублюються.

## Збірки

- `extension/dist`, `artifacts/ai-translator-1.2.0.zip`: робочий API та `balubenko-stripe.web.app`.
- `extension/dist-test`, `artifacts/ai-translator-1.2.0-test.zip`: staging API та `balubenko-stripe-test.web.app`.
- Обидві збірки зберігають ID `aieamemimbcbbnmakifejomadhegogge` і чинний Google OAuth. Встановлювати їх потрібно по черзі або в різних профілях Chrome.
- Перед покупкою background повторно звіряє середовище збірки, `/v1/me.billing` та публічний конфіг білінгу. Історія покупок також перевіряє середовище. Помилка білінгу не блокує звичайний переклад.
- Інтерфейс показує місячну квоту, придбані залишки, резерви й доступний загальний обсяг. Після повернення з оплати баланс оновлюється; доступна й ручна кнопка оновлення.

## Перевірено

- 85 тестів центрального білінгу на Firebase Emulator, TypeScript та браузерні сценарії сторінок оплати й адмінки.
- 157 backend-тестів перекладача, включно з Firestore Emulator; 39 тестів розширення, включно з Playwright; обидві збірки й пакування.
- Реальна оплата Stripe test через hosted Checkout → webhook → OIDC → 50 000 слів і 2 зображення в staging.
- Контрольний переклад «Hello world» через staging Cloud Tasks/AI завершився; використано 2 безкоштовні слова, резерв звільнено, придбаний залишок збережено.
- Test/live мають окремі Stripe Customers для того самого Google-акаунта, каталоги, замовлення та баланси. Тестового замовлення немає в live-даних.
- Live Checkout створено з USD і вимкненою конвертацією та закрито без оплати. Справжнє списання $4.99 власник підтверджує у Checkout.
- Старі вкладки test не можуть змінювати live-дані; LocaleStress спрямовується у свій тестовий кабінет. Ручний Google-вхід у звичайному профілі користувача залишається окремою перевіркою.

При конкуренції Firestore-транзакцій додано обмежений повтор із затримкою лише для підтверджених `Aborted`; бізнес-помилки та невідомі результати не повторюються. Одночасні переклади не можуть витратити останні придбані слова двічі.

Розгортання не видаляє й не переносить наявні робочі акаунти, місячне використання, ручні Pro grants або завдання. Поточні образи й адреси записані в `deployment.json` та `deployment.test.json`. Секрети залишаються в Secret Manager. ZIP у Chrome Web Store не публікувався.

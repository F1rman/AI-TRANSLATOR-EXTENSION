| Тариф | Слів на місяць | Картинок на місяць |

| Free | 100 000 | 0 |

Період — календарний місяць UTC, оновлення першого числа о 00:00 UTC. Значення
розраховані з попереднього 30-денного обсягу; фактичне списання рахує слова Unicode.
Редагування JSON потребує повторного розгортання сервера. Опис підрахунку,
резервування та переходу зі старих добових лічильників — у [backend/README.md](../backend/README.md#configuration).

Сервер розгорнуто в `ai-translator-ext`, Cloud Run `ai-translator-api-00004-f8f`.
Старі змінні середовища добових квот видалені. Публічні головна сторінка, політика
приватності й допомога оновлені та перевірені після розгортання.
Безстроковий Pro для `dev.watersport@gmail.com` підтверджено без зміни доступу.

Перевірки:

- Backend: 123 тести, включно з Unicode, межами місяця й року, паралельними
  запитами, тарифами, поверненням резервів та старими добовими завданнями.
- Extension: 33 тести; TypeScript, production build і перевірка зібраного
  розширення в Chromium пройшли. ID збережений: `aieamemimbcbbnmakifejomadhegogge`.
- Живий текстовий Cloud Task списав 2 слова один раз. Повторна доставка й
  скасування не спричинили повторного списання. Звіт: `artifacts/backend-smoke-1.1.1.json`.
- Живий image Cloud Task створив PNG за 19 секунд і списав одну картинку без
  списання слів. Перевірені власник, приватність файлів, повторний запит,
  скасування та звільнення резерву. Звіт: `artifacts/image-smoke-1.1.1.json`.
  Ізольовані тестові документи й файли видалені; квота користувача не витрачалася.

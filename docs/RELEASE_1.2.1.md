# AI Translator 1.2.1

Тестова покупка зараховується лише в test backend. Для неї потрібно встановити `artifacts/ai-translator-1.2.1-test.zip` або завантажити `extension/dist-test` через `chrome://extensions`. Ця збірка має назву **AI Translator (Test)**. Для справжніх платежів використовується звичайна збірка з `extension/dist` та `artifacts/ai-translator-1.2.1.zip`.

Обидві збірки зберігають ID `aieamemimbcbbnmakifejomadhegogge`, тому в одному профілі Chrome потрібно замінити попередню збірку, а не встановлювати дві одночасно. Можна використовувати окремі профілі Chrome. Після встановлення увійдіть тим самим Google-акаунтом і натисніть «Оновити баланс».

Інтерфейс явно показує «Робочий баланс» або «Тестовий баланс» та пояснює розділення покупок. Окремі повідомлення відрізняють розбіжність середовищ, призупинені покупки, старий API та тимчасову недоступність.

Перевірка central config раніше завершувалась через 5 секунд, хоча журнал сервера підтвердив успішну відповідь через 5,3 секунди. Тепер доступні 10 секунд на спробу та один повтор лише для network/timeout, HTTP 408/429/5xx. Неправильна конфігурація чи середовище не повторюються. Залишок, отриманий із backend перекладача, зберігається навіть при недоступному білінгу.

Покупки, слова та зображення між test і live не переносяться. Серверні ліміти та ціни не змінені; розгортання backend для цього випуску не потрібне.
